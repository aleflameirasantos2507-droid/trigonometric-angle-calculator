# Trigonometric Angle Calculator

A beginner-friendly Python project that calculates the sine, cosine, and tangent of a user-provided angle.

## Features

- Accepts an angle in degrees as input
- Converts degrees to radians automatically
- Calculates:
  - Sine
  - Cosine
  - Tangent
- Displays results formatted to two decimal places

## Technologies Used

- Python 3
- Built-in `math` module

## How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/trigonometric-angle-calculator.git
```

2. Navigate to the project folder:

```bash
cd trigonometric-angle-calculator
```

3. Run the script:

```bash
python main.py
```

## Example

### Input

```text
Enter any angle: 45
```

### Output

```text
The angle 45° has:
Sine: 0.71
Cosine: 0.71
Tangent: 1.00
```
